# ROAM v0.26 — Codemagic build, installation and safe iPhone tests

## 1. Preserve v0.25 first

- Back up your known-good **Roam v0.25 FULL SOURCE** ZIP and the installed/tested IPA.
- Keep the original **LocalDevVPN** app and existing pairing file. Do not uninstall either.
- In GitHub Desktop use a new branch, suggested `roam-v0.26`.

## 2. Compile using your existing Windows → GitHub → Codemagic → iLoader workflow

1. Unpack `Roam_v0.26_FULL_SOURCE.zip` into the Roam repository root. Expected top-level entries include `Locus`, `Locus.xcodeproj`, `Vendor`, `project.yml`, `codemagic.yaml` and this guide. Alternatively overlay `Roam_v0.26_PATCH_FROM_v0.25.zip` onto a **clean v0.25** source tree.
2. Commit and push the new branch.
3. In Codemagic run the **`roam-ios-unsigned`** workflow.
4. Check for **Roam 0.26.0 (26)** and `roam-v0.26-unsigned.ipa` in the build artifacts. Check the first actual Xcode error in `roam-build.log` if it fails; Swift syntax validation on Linux does not substitute for iOS compilation.
5. Install and sign with your established iLoader procedure. Ensure both shortcuts' **Open App → Roam** target selects the new v0.26 installation if an older Roam remains on the iPhone.

## 3. Baseline regression (toggle OFF)

1. Start Wi-Fi **OFF**, cellular **ON**, original LocalDevVPN **Connected**. Select a map destination in Roam.
2. Open the **Wi-Fi-free startup** guide. Confirm pairing file exists and check the **I checked LocalDevVPN is Connected** toggle.
3. Leave **Automatically run Data On after accepted teleport** **OFF**.
4. Tap **One-tap: Go offline & start teleport**. `Roam Data Off` should turn cellular data OFF and reopen the *correct* Roam installation.
5. Observe **One-shot teleport request accepted**, then independently check Apple Maps. Tap **Restore mobile data now** or the usual **Restore mobile data** action. Confirm cellular data is back ON and Apple Maps remains at the simulated location.
6. Re-teleport to a new pin with cellular ON and Wi-Fi OFF. This must still work as in v0.25.

## 4. New v0.26 experimental automatic second Shortcut

Only after the baseline succeeds, and when you want to test a fresh one-tap cycle:

1. Ensure LocalDevVPN says **Connected**, Wi-Fi OFF, cellular ON, selected destination, and no unwanted movement. Do not unnecessarily end a functioning session.
2. Open the guide, check the VPN confirmation toggle and **explicitly enable** **Automatically run Data On after accepted teleport** for this attempt.
3. Tap **One-tap: Go offline & start teleport**. `Roam Data Off` should take cellular OFF and reopen Roam. After the local GPS API accepts the one-shot teleport, Roam waits around **2 seconds while active** and requests `Roam Data On` without another button press.
4. The second Shortcut should switch cellular ON and reopen the new Roam installation. Check the guide's return indicator; a detected cellular route does **not** confirm the radio toggle. Confirm real cellular service and check the simulated position in **Apple Maps**.
5. Re-teleport normally after cellular is restored. For reliability, repeat the complete sequence a few times and compare the **STARTUP RELIABILITY** counters. Counters represent local API results and observed paths, not independent Apple Maps checks.

## 5. Safety and recovery

- **No GPS API success:** auto-restore is **not** launched. Restore mobile data using the guide's regular manual button or Settings, and inspect LocalDevVPN/pairing.
- **App leaves the foreground during the 2-second hand-off:** auto-restore cancels. Tap the regular Restore mobile data button later. There is no delayed background action.
- **Shortcuts do not open / wrong Roam installed:** repair shortcut names or their Open App target; manually restore mobile data in iPhone Settings.
- **VPN disconnected:** turn cellular on, reconnect the **original** LocalDevVPN, and retry from the guide. No engine or VPN reset is performed automatically.
- **Returned after restoring but path doesn't show cellular:** confirm iPhone mobile data is truly on and that there is signal; the monitor alone isn't conclusive.
- **90-second one-shot window expires:** pending teleport is disarmed. No unexpected later GPS command should occur.
- **Cancel an armed teleport:** use Cancel armed teleport. For a scheduled auto-restore, tap Cancel automatic restore during the brief hand-off interval.
- **Counters:** on-device simple totals only; Reset reliability counters clears these new v0.26 statistics.

## 6. What has been validated locally

- All 25 `.swift` files passed `swiftc -frontend -parse` syntax checking on Linux, **not** Apple SDK compilation/type checking.
- `project.yml` and `codemagic.yaml` YAML parse correctly, `Locus/Resources/Info.plist` parses correctly, project file version is aligned.
- ZIP archives pass integrity testing. The v0.26 patch was generated by a byte comparison with the supplied v0.25 full-source ZIP.
- Core location/paired developer connection, VPN/pairing and cruise engine source files are identical to v0.25.

**Not yet verified:** successful iOS Codemagic compilation, real-world 2-second Shortcuts hand-off and reliability of repeated v0.26 cycles. Treat those as tests rather than guarantees.
